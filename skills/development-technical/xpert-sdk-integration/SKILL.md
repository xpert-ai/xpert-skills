# XpertAI SDK Integration

Use the XpertAI SDK in your own service, script or custom interface without the Xpert platform plugin system or ChatKit.

## Official Resources

- [SDK documentation](https://docs.xpertai.cn/zh-Hans/ai/agent/development-api)
- [SDK repository](https://github.com/xpert-ai/xpert-sdk-js)

## Guidance

Read the latest official resources before implementation. Integrate the official SDK within the calling project; platform plugin development, registration and ChatKit integration are outside this skill's scope.

Follow the current official documentation for installation, configuration, APIs and examples. This skill provides reference links rather than maintaining copies of those details. If the official documentation is unavailable, report the limitation instead of substituting old OpenAPI calls for the documented SDK integration.
