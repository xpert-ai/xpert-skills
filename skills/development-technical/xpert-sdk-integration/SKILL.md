# XpertAI SDK 独立应用接入

适用于在自己的服务、脚本或自建界面中单独使用 XpertAI SDK，不使用 Xpert 平台插件体系和 ChatKit。

## 官方资料

- [SDK 官网文档](https://docs.xpertai.cn/zh-Hans/ai/agent/development-api)
- [SDK 官方仓库](https://github.com/xpert-ai/xpert-sdk-js)

## 使用原则

实现前读取上述官方资料的最新内容，在调用方项目中通过官方 SDK 完成接入；此场景不涉及平台插件的开发和注册，也不引入 ChatKit。

安装方式、配置、接口及示例均以官网当前说明为准。本技能只保留资料入口，不维护这些内容的副本。若官网无法读取，说明限制，不用记忆中的旧 OpenAPI 调用方式代替 SDK 官方说明。
